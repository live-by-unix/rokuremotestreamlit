# Roku Remote Streamlit

A Streamlit app for controlling Roku devices remotely. This is an experimental project and may contain bugs.

## Description

This application provides a web-based interface for interacting with Roku devices using Streamlit.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
streamlit run app.py
```

## Notes

- This project is in active development
- There may be bugs and unexpected behavior
- Feedback and contributions are welcome
